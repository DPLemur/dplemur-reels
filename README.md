# dplemur-reels

## Правила для новых рилсов

### Синхрон между кадрами «Wear it → Style it → Live in it»

Все три примера цветовой гаммы показывают **одного и того же героя**:

1. **Wear it** — герой (пол, возраст, стиль задаются здесь).
2. **Style it** — вещи и аксессуары, которые носил бы именно этот человек.
3. **Live in it** — интерьер, в котором жил бы именно этот человек.

- Если на первом кадре девушка, женщина, девочка или бабушка — вещи на втором кадре должны подходить ей, а интерьер на третьем — её дому.
- Если на первом кадре мужчина или ребёнок — то же самое для них.
- Не смешивать: никаких женских вещей после мужчины с ребёнком, никаких этнических мотивов (например, афро), если герой к ним не относится.
- Пример нарушения: `roller` — отец с сыном → женская одежда и туфли → афро-интерьер.
